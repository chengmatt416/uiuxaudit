| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `uiuxaudit` seriously. If you believe you have found a security vulnerability in this project, please report it responsibly:

1. **Do not disclose it publicly** via GitHub issues, discussions, or social media.
2. Email details of the vulnerability to **chengmatt416@gmail.com**.
3. Please include:
   - A description of the issue and potential impact
   - Step-by-step reproduction instructions or a proof-of-concept
   - Any mitigations or suggested fixes you have developed

We will acknowledge receipt of your report within 48 hours and work with you to validate and remediate the issue before public disclosure.
